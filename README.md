This application can be used to train the Trachtenberg speed system of basic mathamatics, in particular multiplication, division, addition, squares and square roots. 

You just need to select the "gamemode" (multiplication rules, multiplication NxN, division, addition ecc.), the "gamerule" (just for multiplication rules (x2,x3,x4 ecc.)
 the number of digits you want to "play" with and for the addition section the number of addends. For every box you can select there is a RDN (Random) button that 
 randomizes the respective box. In particular select a range of numbers (ex. 3-6) in "number of addends" and "number of digits" will result in respectevely
 a random number of addends and a random number of digits. 
 In the division and square roots section there is R button, it stands for REMAINDER: basically when performing calculations such as 5/2 the result should be presented 
 in the form "2 R 1" that means "2 with a remainder of 1". In the case of square roots the remainder it's just the difference between the number presented N and
 the biggest square smaller of N (ex. N = 2200, sqrt(2200) = 46 R 84). Up to this basic version of the app i have no will and no competence to add a system that 
 checks for decimals :/
